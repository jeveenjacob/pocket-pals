# Pocket Pals

Pocket Pals is a colorful, kid-friendly virtual pet game built as one self-contained HTML file. Children can choose a cute pet, customize its color, care for it, chat with it, learn facts, and play animated activities.

## Pets

- Cat — walks around and chases a ball of wool
- Dog — wanders and fetches a stick
- Bird — flies and fetches small objects
- Bunny — hops and chases a carrot
- Pixel Pal — a retro pixel-style companion

## Features

- Six pet colors
- Custom pet names
- Hunger, cleanliness, and energy meters
- Feeding, bathing, and adjustable sleep time
- Pet-specific conversations and care requests
- 120 educational facts across maths, science, history, English, geography, and art
- Automatic pet movement and kid-triggered activities
- Responsive layout for computers, tablets, and phones
- No installation or external assets required

## Play locally

Download or clone the repository, then open `index.html` in a modern web browser.

```bash
git clone https://github.com/jeveenjacob/pocket-pals.git
cd pocket-pals
```

Then double-click `index.html`.

## Technology

Pocket Pals uses plain HTML, CSS, and JavaScript. Everything is contained in `index.html`.
